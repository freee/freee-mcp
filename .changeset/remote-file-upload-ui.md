Remote MCP でファイルボックスへのファイルアップロードに対応（MCP Apps アップロード画面）

- `freee_file_upload_ui` ツールを追加。会話内にアップロード画面を表示し、選択したファイルはブラウザから直接送られるため、LLM のツール引数や MCP リクエストボディのサイズ制限を受けない（1 ファイル 64MB まで、複数選択可）
- 画面からのアップロードを受け付ける `POST /upload/receipts` エンドポイントを追加（短期間有効なアップロードチケットで認証、現在の事業所に固定）
- MCP Apps 非対応クライアント向けにテキストのフォールバック案内を返す
