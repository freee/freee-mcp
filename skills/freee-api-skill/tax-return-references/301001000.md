# 欠損金の繰戻しによる還付請求書

<!-- markdownlint-disable MD013 -->

- sheet_code: `301001000`
- 電子申告: 未対応（XTX なし）
- 取得API: `GET /hub/tax_return/corporate/sheet/national/{tax_return_id}/301001000`
- レスポンス: XML。様式部は `/data/loss_carryback_refund` 配下
- 共通仕様（xpath 表記の規則・名前空間・共通ヘッダ）は [`index.md`](./index.md) を参照。

## xpath 表記の規則

電子申告未対応帳票。電子申告未対応帳票のため、xtx内にXTXキーではなく意味のある英語キーでサブキーを定義する

- 項目: `/data/loss_carryback_refund/{項目キー}`。XTX タグ名ではなく意味のある英語キーが要素名になる
- 日付など複数の値を持つ項目は `{項目キー}_{サブキー}` の要素に分かれる（例: `submission_date_year`）。親要素は存在しないため、親行の xpath は空欄で、`└` の行が実際の要素を指す
- 値が nil の項目は `<要素 nil="true"/>` の空要素として出力される
- 名前空間は使用しない
