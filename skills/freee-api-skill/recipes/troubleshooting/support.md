# API の機能制限とサポート窓口

## API の機能制限に関する問題

freee API 自体が対応していない操作は、freee-mcp（クライアント）側では解決できない。以下は API の機能制限に該当する。

- 特定の承認経路（部門・役職ベース等）で API から申請ができない
- 特定の条件（外貨を含む等）のデータが API で取得できない
- Web UI では可能な操作が API では提供されていない
- 特定のエンドポイントやフィールドが存在しない

このような場合は freee Public API リクエストフォームから要望を送信する。API の機能制限を freee-mcp の GitHub Issues に報告してもクライアント側では対応できない。

- freee Public API リクエストフォーム: https://docs.google.com/forms/d/e/1FAIpQLSdG19OrIdc0nbI-F5L1hkYRAfh4l-qD0ugvuFqxvaOUdXVqXg/viewform

## 問い合わせ先

- freee API 公式ドキュメント: https://developer.freee.co.jp/docs
- freee-mcp（MCP サーバー）自体の不具合・改善要望: https://github.com/freee/freee-mcp/issues
- API の機能拡充・改善の要望: 上記の freee Public API リクエストフォーム

freee サポートでは freee-mcp に関する問い合わせは受け付けていない。
