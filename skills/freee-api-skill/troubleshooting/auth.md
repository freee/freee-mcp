# 認証のトラブルシューティング

## 接続モードの確認

`freee_server_info` の transport フィールドで現在の接続モードを確認できる。`remote` なら Remote MCP、`stdio` ならローカルモード。

## Remote MCP での認証

Remote MCP では認証は MCP OAuth プロトコルにより自動的に処理される。初回接続時にブラウザで freee へのログインが求められる。

認証に問題がある場合:

1. ブラウザのポップアップブロックを確認する
2. AI ツール（Claude Desktop 等）でカスタムコネクタを一度削除し、再度追加する
3. freee に別タブでログインしてからリトライする

## 401 Unauthorized

原因: 認証トークンの有効期限切れ。

- Remote MCP: MCP クライアントが自動的に再認証を促す。解決しない場合はカスタムコネクタを再追加する
- ローカルモード: `freee_authenticate` を実行して再認証する

## 403 Forbidden

原因: 必要な権限がない、またはレートリミット。

1. freee 開発者ポータルでアプリケーションの権限を確認する
2. 必要な権限が有効化されているか確認する
3. 権限を追加した場合は `freee_clear_auth` → `freee_authenticate` で再認証する

レートリミットの場合は数分待ってから再試行する。

## OAuth 認証画面が表示されない（ローカルモード）

原因: ブラウザがブロックしている可能性がある。

1. ポップアップブロックを一時的に無効化する
2. 手動でコールバック URL にアクセスする
3. 別のブラウザを試す
